### 시작 동기
파트장 진급 후 사내 관리자 스터디의 두번째 책.  
인텔의 회장이 작성한 책으로 개발자, 엔지니어가 읽으면 더욱 도움이 될것같다.

사실 피터 드러커의 자기경영노트는 나쁘지 않았지만 와닿지 않거나 추상적이였던 부분이 많았다.
이책으로 조금더 실질적인 해답이 주어지면 좋을것 같다고 생각하며 책을 읽어 나가려한다.

### 진행 계획
분량: 주 1~2장(사내 스터디 일정에 따름)
독서일정: 주단위로 진행
